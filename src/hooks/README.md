# 🪝 Hooks Customizados

Esta pasta contém os **Custom Hooks** do React. O objetivo aqui é extrair lógicas complexas de estado e ciclo de vida de dentro dos componentes e páginas.

## O que colocar aqui?
- Hooks para gerenciamento de autenticação (`useAuth`).
- Hooks para lidar com lógicas de formulários complexos.
- Hooks para controle de estado global ou de UI (ex: `useModal`, `useSidebar`).

## Regras da Pasta
- Todo arquivo e função deve começar com o prefixo `use` (ex: `usePacientes.ts`).
